## Lessons
- When `ai3_shell.sh` reports "auth expired" + 401, the API keys are stale
  AND the Safari session is likely dead. The SSO bridge
  (`HUANXIN_ALLOW_SAFARI_SSO_BRIDGE=1`) only helps if Safari is already
  logged in. Without stored phone/password creds, this is a hard blocker
  requiring human action.
- Always run this project's tests with `.venv/bin/python`, not system
  `python3` — `eval7` is a required fallback dependency for hand evaluation
  with non-standard board states.
- A stale daemon can hold the port (19003) even after its browser session
  dies. `kill <pid>` frees it; a fresh daemon will be spawned on next
  `ai3_shell.sh` invocation.
