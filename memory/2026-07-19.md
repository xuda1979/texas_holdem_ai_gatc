## Insights
- A `Protocol` is the right fix when a helper accepts both a mock and a
  real engine class — avoids `Any` and keeps call-site type-checking.
- mypy "no-redef" on try/except import fallbacks needs an explicit
  `# type: ignore[no-redef]`, not just `[override]`.
- Stale `# type: ignore[wrong-code]` comments hide real errors; mypy
  helpfully flags the mismatch — always fix the code, not the code in
  the ignore.
- When a function returns `tuple[A, B, C] | tuple[A, B, C, D]`, slicing
  `[:3]` is a clean way to narrow to 3 elements without a cast.
- `torch.multinomial(...).item()` returns `int | float` depending on
  tensor dtype; always wrap in `int(...)` when passing to APIs that
  require `int`.
