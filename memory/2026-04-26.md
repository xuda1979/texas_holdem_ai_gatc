
## Distributed self-play worker IPC fix
- Re-ran supported venv full suite with `.venv/bin/python -m pytest -q`; found one failure in `tests/selfplay/test_workers.py`.
- Root cause: `DistributedSelfPlay` workers returned raw replay buffers containing `torch.Tensor` objects, triggering PyTorch shared-memory IPC (`torch_shm_manager`) and failing in sandboxed macOS/CI environments.
- Fixed `src/poker_ai/selfplay/distributed_self_play.py` to return compact pickle-safe hand summaries from worker processes instead of raw tensor buffers.
- Added regression tests in `tests/selfplay/test_workers.py` covering tensor-buffer summaries and unpickleable payload fallback.
- Validation: `tests/selfplay/test_workers.py` passes; full supported venv suite passes: 294 passed, 2 skipped, 1 warning.
