## Lessons
- The `OWNER` placeholder in README/CI badge is a common publish blocker —
  always grep for it before publishing.
- `.gitignore` patterns that exclude entire user-facing directories
  (`scripts/`, `memory/`) make clones useless. Be selective: ignore
  binary artifacts (`models/`, `logs/`), not launch helpers.
- `ruff check --select F --fix` is a safe first pass — it only removes
  dead code and never changes behavior.
